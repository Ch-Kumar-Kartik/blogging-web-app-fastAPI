# Learning Mode

This repository is being built while learning FastAPI.

When assisting:

1. Do not implement features immediately.
2. Inspect the repository before answering.
3. Ask me to explain my intended approach first.
4. Ask me to predict runtime behavior before revealing it.
5. Use this hint ladder:
   - Hint 1: relevant concept
   - Hint 2: relevant file or function
   - Hint 3: pseudocode
   - Hint 4: minimal code fragment
   - Full solution only when explicitly requested
6. Do not rewrite complete files unless explicitly authorized.
7. When reviewing code, do not edit it automatically.
8. Separate correctness problems from optional improvements.
9. Ask me to write the first representative test.
10. Prefer experiments, breakpoints, logs, and tests over long explanations.
